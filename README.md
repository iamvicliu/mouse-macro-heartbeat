# 鼠标宏心跳 · MouseMacroHeartbeat

> 你的循环宏现在是开着还是关着？屏幕角落一眼就知道。

只要在宏里加一步 `F8`，桌面角标就会跟着宏的状态变：**绿=开，橙=关**。

![四种状态](docs/states.png)

---

## 你肯定遇到过这些情况

- 以为宏开着，结果上一轮就被切出去了
- 以为宏关了，其实还在后台疯狂循环
- 切了窗口、换了配置、换了个宏，完全不知道状态变了

各家宏软件都是在**驱动层**跑宏的，游戏里、系统里都看不到"它到底还活着没"。

这个工具用一个很土但很可靠的办法解决：**让你的宏每循环一轮，顺手敲一下 `F8`。**

收到 F8，角标变绿；超过一段时间没收到，角标变橙。宏的死活一眼就看见。

> **名字叫「鼠标宏」，但能力面向所有宏。**
> 键盘宏键（G 键、M 键）、键盘宏、手柄宏……只要能在这段循环里插一步 `F8`，就一样能用。
> 脚本从头到尾只认那个信号键，不关心它是哪个软件、哪个设备发出来的。

---

## 它能做什么

- **四种状态一眼可见**：灰=待机，绿=开，橙=关，红=未提权
- **托盘图标同步变色**：蓝问号 / 绿盾对勾 / 红叉
- **声音提示**：开宏一声高音，关宏一声低音
- **自动适应你的宏节奏**：改了宏的快慢，不用改代码
- **不注入游戏、不读写内存、不代替你操作**：只监听一个按键，然后画个角标

## 怎么用（3 步）

**1. 装 AutoHotkey v2**

去 <https://www.autohotkey.com/> 下载安装即可。需要 **v2.0** 或更高（**不是** v1.1，两个版本语法不兼容）。

**2. 双击 `鼠标宏心跳.ahk`**

弹出 UAC 点「**是**」。托盘出现蓝色问号图标，屏幕右下角出现灰色 `宏：待机`。

> 脚本需要管理员权限才能安装全局键盘钩子。放在普通文件夹里（别放 `C:\Program Files`）会更省事。

**3. 在宏里加一步 F8**

打开你的循环宏，动作列表里**添加一步「键盘按键 F8」**，保存。

> ⚠️ 放在**循环内部**，且**每轮只发一次**。
> 放在循环外只会发一次，脚本就以为宏停了。

## 各家宏软件怎么加 F8

| 软件 | 在哪加 |
|---|---|
| 罗技 G HUB | 宏编辑界面 → 动作列表 → 添加「键盘按键」→ 按 F8 → 保存 |
| 雷蛇雷云 | 宏模块 → 录制或添加按键 → F8 |
| 海盗船 iCUE | Actions → Macro → 添加按键 F8 |
| SteelSeries GG | Engine → 宏编辑器 → 添加按键 F8 |
| 国产鼠标 / 键盘驱动 | 找「宏 / Macro」→ 添加动作 → 键盘 → F8 |
| 开源替代工具 | 同上，在序列 / 动作里插入键盘 F8 |

**通用原则**（比具体菜单更重要）：

1. F8 必须在**循环体内部**，每轮走一次
2. 每轮**只能发一次** F8，发两次间隔就减半，脚本会算错
3. 宏可以绑在任何键上（G4 / G5 / 中键 / 键盘键都行），脚本不关心

## 常见问题

**Q：角标一绿一橙来回闪？**

超时阈值小于宏一轮的时长。正常情况下脚本会自己测（`AutoTimeout := true`），跑满两轮就自动校准。

如果还闪，手算：**阈值 = 宏一轮时长 + 2000ms**，把宏里所有 delay 加起来就是一轮时长。

**Q：完全没反应，一直是灰的？**

看脚本同目录的 `signal.log`：

- 有 `RX` 行 → 信号收到了，问题在显示侧
- 没有 `RX` 行 → 信号没进来，继续查：
  1. 日志第一行是不是 `admin=1`？不是就说明没提权
  2. 宏里到底有没有 F8 这一步？是不是放循环外了？
  3. F8 是不是被别的软件占了？

**Q：红底显示「未提权」？**

UAC 点了「否」。退出脚本重新打开，点「是」。

**Q：F8 和游戏按键冲突？**

托盘图标右键 →「更换信号键」，按下想用的键即可（本次运行生效）。

想永久改就编辑脚本顶部 `SignalKey := "F10"`（或 Pause、ScrollLock），宏里也同步改。

**Q：进游戏后角标不见了？**

游戏如果开「全屏独占」模式，任何置顶窗口都盖不上去。改成「无边框窗口」或「窗口化全屏」。

**Q：关宏后为什么要等 7 秒才变橙？**

因为要等"下一次 F8 本该到却没到"才能确认宏停了。判定时间不可能短于宏一轮的时长，这是原理决定的，不是卡顿。

**Q：开机自启，但不想每次弹 UAC？**

用「任务计划程序」建一个任务：触发器 = 登录时，勾选「使用最高权限运行」。然后删掉启动文件夹里的旧快捷方式，否则会开两个实例、两个角标叠在一起。

## 配置项

全在 `鼠标宏心跳.ahk` **文件顶部**，用记事本改，改完右键托盘图标 → 重载脚本。

| 配置项 | 默认值 | 作用 |
|---|---|---|
| `SignalKey` | `"F8"` | 信号键。改这里，宏里也要同步改 |
| `PassThroughSignalKey` | `false` | `false` = 吞掉 F8，游戏收不到 |
| `AutoTimeout` | `true` | 自动测算超时阈值 |
| `F8Timeout` | `8000` | 固定阈值，仅 `AutoTimeout=false` 时生效 |
| `TimeoutFactor` | `1.05` | 自动阈值 = 中位数 × 该系数 + `TimeoutPadMs` |
| `TimeoutPadMs` | `400` | 自动阈值的额外余量（毫秒） |
| `SoundOn` | `true` | 状态切换提示音 |
| `SelfTestKey` | `"F9"` | 自检键，按一下等于模拟收到信号 |
| `OsdCorner` | `"BR"` | 角标位置：`BR` / `BL` / `TR` / `TL` |
| `OsdMarginX` | `24` | 角标距屏幕边缘（水平，像素） |
| `OsdMarginY` | `12` | 角标距屏幕边缘（垂直，像素） |
| `OsdFontSize` | `19` | 字号（也可以在托盘菜单「外观设置」里调，10~40） |
| `OsdAlpha` | `245` | 不透明度（60~255，越大越实；同样可在「外观设置」里调） |
| `OsdShowIdle` | `true` | 待机时是否显示角标 |
| `FollowForegroundMonitor` | `true` | 角标跟随当前活动窗口所在显示器 |
| `MonitorIndex` | `1` | 不跟随时固定用第几个显示器 |
| `AutoElevate` | `true` | 权限不足时自动请求提权 |
| `LogEnabled` | `true` | 写 `signal.log` |

## 原理（技术细节）

### 为什么要发 F8，而不是直接监听侧键

各家的宏都在**驱动层**执行。侧键事件不会以普通按键的形式流到系统输入队列，脚本监听不到，也没必要监听。

所以反过来做：**让宏自己发一个信号**。宏每循环一轮敲一下 F8，脚本收到 F8 就等于"宏还活着"。

好处是彻底解耦：

| 你改什么 | 脚本要不要改 |
|---|---|
| 换触发键（G4 → G5） | 不用 |
| 换鼠标 / 换驱动软件 | 不用 |
| 改宏的技能顺序 | 不用 |
| 改宏的快慢节奏 | 不用（自动测算阈值） |

### 心跳判定

```
收到 F8  → 记录时间戳，角标变绿
        ↓
每 250ms 检查一次：当前时间 - 最后时间戳 > 阈值 ?
        ↓
是  → 判定宏已停，角标变橙
```

### 阈值怎么算

脚本记录最近 5 次 F8 的间隔，取**中位数**（不是平均值，避免一次卡顿把结果带偏），套公式：

```
阈值 = 中位数 × 1.05 + 400ms
```

实测：一个 6414ms 一轮的宏，测出来 6468~6500ms，阈值落在 7190~7230ms，关宏后约 7.3 秒变橙。

想用固定值就把 `AutoTimeout := false`，然后设 `F8Timeout = 宏一轮时长 + 2000`。

> ⚠️ 阈值小于一轮时长会怎样：宏还在跑，角标却每轮闪一次橙、响一声低音。

### 权限要求

脚本需要**管理员权限**，因为：

- 游戏常以管理员运行，普通权限的进程受 UIPI 限制，收不到发往高权限进程的按键
- 全局键盘钩子 + 覆盖全屏窗口都需要足够权限

### 日志格式

`signal.log` 里关键就三种行：

```
RX signal -> ON             收到第一个信号，判定宏开启
INTERVAL 6484ms             两次信号之间的间隔
AUTO timeout -> 7209ms      自动算出的新阈值
TIMEOUT 7312ms > 7209ms     超时，判定宏关闭
```

排查时先看有没有 `RX`，这一步就能把问题二分掉一半。

## 免责声明

本工具**不注入游戏、不读写游戏内存、不代替你操作**，只监听你自己宏发出的一个按键，然后画一个窗口。

但它需要**管理员权限 + 全局键盘钩子**。部分游戏的反作弊系统对这类程序比较敏感，**竞技类网游请谨慎使用，风险自负**。

另外，使用自动化宏是否符合具体游戏的用户协议，请自行判断并承担后果。

### 会不会被封号？

**没有工具能承诺绝对安全**，包括这个。

能说清楚的是：

- 这个脚本只做**监听 + 画窗口**，不碰游戏进程
- 它把 F8 吞掉（`PassThroughSignalKey := false`），游戏根本收不到这个键
- 但它确实在全局钩键盘，这类行为本身在反作弊眼里是可观察的

**真正让宏容易被识别的是宏本身，不是这个提醒工具**：

- 按键间隔完全恒定（比如每次都 533ms、几个小时不变）
- 真人操作会有 20~40% 的抖动，而机器没有
- 检测代码只要统计间隔的标准差，接近 0 就露了

所以如果你担心，改宏比改脚本有用：给每个 delay 加点随机抖动，别长时间不间断挂机。
